## Pruebas de funcionamiento sugeridas

1. En móvil, abrir/cerrar Navbar y navegar entre secciones.
2. Buscar creadores por habilidad y filtrar por ciudad.
3. Abrir una ficha `/comunidad/:id`.
4. Crear una tarjeta local; recargar y comprobar que conserva el alias.
5. Publicar una convocatoria local, guardarla y eliminarla.
6. Guardar un evento y comprobar el filtro «Mi agenda».
7. Entrar a `/proyectos/:id` y desplegar una guía.
8. Validar formulario de contacto y abrir una URL inexistente (404).

## Notas

No hay backend de usuarios ni base de datos real en este primer avance. Evitar presentar registros, eventos o postulaciones como operaciones reales. Las imágenes son marcadores SVG mostrados mediante etiquetas HTML `<img>`.
